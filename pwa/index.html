Masukkan ekspor grup WhatsApp

Pilih ZIP dari satu grup, kirim ke workflow n8n, lalu periksa apakah pesan dan sumbernya terbaca dengan benar.

Mode preview. Workflow yang sekarang hanya mengurai ZIP dan menampilkan contoh. Pesan belum disimpan ke Supabase dan belum menjadi task. Gunakan Test URL saat n8n sedang Listen for Test Event; jangan gunakan Production URL dulu.

Di n8n: buka Receive ZIP → Test URL → Listen for Test Event → salin URL.

Gunakan ekspor satu grup. ZIP harus memiliki tepat satu file chat .txt.

Arsip chat berisi informasi pribadi. URL Test tidak memakai autentikasi, jadi jangan bagikan URL atau hasil preview. PWA ini belum untuk impor produksi.
